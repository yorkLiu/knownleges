5月复盘：撕裂的市场，清醒的投资者
调仓记录
这个月的市场，用两个字概括：撕裂。

一、“冰火两重天”的结构

火的一边：AI算力（CPO、PCB）、半导体、电力——科技与高端制造的主线贯穿全月，部分龙头涨幅惊人。如果你没重仓这些，很容易“满仓踏空”。

冰的一边：地产、消费、金融等传统板块持续低迷，前期热门题材（低空经济、商业航天）月末大幅回调。

核心特征：成交量萎缩，存量博弈。资金拆东墙补西墙，热点快速轮动。在这种环境下，亏损是大多数人的常态——你不孤单。

二、亏损的根源：节奏，而非方向

追涨杀跌：看见大涨追进去，往往买在短期高点。
持有非主线品种：公司再好，不是市场焦点，也只能被动下跌。
被波动震出局：恐慌卖出，多半卖在最低点。

请明白：在这种高难度市场中，短期亏损不代表你的能力有问题，更多是环境使然。

三、从“亏麻了”到“学到了”

接纳情绪，但不被主导。冷静是投资的第一品质。
复盘，而非抱怨：每一笔交易——成功的靠逻辑还是运气？失败的因为逻辑被证伪还是情绪波动？有没有更清晰地看清当前市场的运行规律？
审视持仓逻辑：公司基本面、行业前景变了没有？如果长期逻辑坚实，短期波动就是情绪馈赠。
规划，而非预测：如果继续调整，现金流能否支撑？结构是否需要优化？有没有一直看好但之前太贵、现在可以关注的标的？

四、几个温暖的提醒

长期主义是穿越波动的唯一法宝。80%的利润来自20%的时间，大部分时间都在等待。
仓位管理是生存的艺术。别让自己处于“赌一把”的境地。
市场永远在。5月结束了，投资生涯还很长。每一次深刻回调都是市场在给你上课——学费虽贵，学到的无价。

当所有人都觉得“亏麻了”的时候，往往也是优质资产出现性价比的时候。

收拾心情，做好复盘。6月，重新出发。你不是一个人在战斗，时间会奖励有耐心的人。
