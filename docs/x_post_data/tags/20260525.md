是市场真的涨不动了？还是A股开始复制美股的剧本——少数优秀公司持续上涨，把指数拉成牛市，多数个股边缘化？

选哪个？自己判断。没人能替你回答。

股市赚了钱，取出去改善生活。任何时候，这都是对的。
