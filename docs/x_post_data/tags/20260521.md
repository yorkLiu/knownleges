别慌，鱼尾虽难啃，但真正的机会，往往在恐慌之后。

动态平衡线：个股强弱的分水岭
今日没动，风控第一
定位：找到那个反复被砸、屡次冲高回落的位置——凹峰、长上影、大阴实体，价格多次触碰并引发回调。这就是动态平衡线，短期最强压。

线下，不玩：股价在线下方，无论怎么震荡、小涨小跌，一律不碰。别在磨叽行情里耗时间。

线上，才看：必须等实体K线突破并站稳。压力变支撑，平衡被打破，向上失衡才是动手的信号。

回踩确认：跳空高开过线？不急。等回踩平衡线，能快速收回，再逐步跟庄。这种踩而不破，是最好的节奏。

加仓规则：突破后出现高量，用高量顶底划线。不破底可低吸；跌破后若快速收回，加仓。连板趋势，往往从这里开始。

简单说：线是规则，突破是信号，回踩是确认，加仓是跟随。不做线下弱势，只做线上强势。
