【我也有測不準的地方】

從昨天，哈爾濱風災證實了咱的「立個旗，神一下」，有些中簡無神論者就又開始「事後諸葛亮」了🤬

大盧的預測跟「兩頭堵」，「倖存者偏差」的區別在哪裡？請看圖！

我原文說的是風災，風災，風災！
而且是覆蓋「從沒發生過大風災的地方」！我準確預測了從6月開始（事實上是5月31日），至於「持續三個月」有待繼續驗證。

據官方媒體報道，哈爾濱在5月31日遭遇了極端強對流與沙塵暴天氣，局地陣風高達13級，13級，13級！

瞬間將白天變為黑夜。冷暖氣流激烈碰撞引發了這次罕見的「鋒面大風」，造成多處設施損壞及交通延誤⋯⋯

瞬間平均風速達每秒26.2公尺，陣風高達每秒38.9公尺（相當於13級風的強度），大風同時席捲了沙塵，導致市區天空一秒變黑，能見度驟降。

綜上，這不是普通的「大風天氣」，而是風災！

如果腦子沒被陰沉木做的棺材板擠過，應該知道「普通刮大風」和「風災」的區別吧？

再說你們意淫的，利用「頻發性，週期性」瞎蒙！我查了一下氣象資料，哈爾濱地區並不是每年都會有「大風」，最近一次「大風」是在2021年11月21日，風力最高10級，時隔五年。除了這次，再大點的風，那就要追溯到2006年了！

各位「大明白」們，請你也提前一個月，整一整「倖存者偏差」，預測個試試？沒病走兩步！

另外，此次我也有沒說準的地方，就是起點有偏。我說的是從「山東開始」，而這次牆國第一次風災是在「東北哈爾濱」。方向為什麼從「東」變成了「東北」，這是需要我自己再找細節，繼續研究糾正的地方。

我沒說過我的預測一定準，但我有自己的體系，不抄襲不二創不洗稿。一次兩次可以瞎蒙，我在外網拋頭露面做預測節目6年了，各種預測實證數不勝數，至今不怕看「合訂本」。咱憑的是祖師爺的垂憐和庇佑，多年打磨出來的真本事，豈是你們熟悉的二創洗稿流量逼們可比的？

這次提前一個月預測「立個旗，神一下」，意在證實我多年的一個心結，也就是目前稍有進展的研究成果。
